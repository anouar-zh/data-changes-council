# Project origin

Data Changes Council started from [OliWoods-Org/llm-council](https://github.com/OliWoods-Org/llm-council).

The upstream repository is distributed under the Apache License 2.0. This repository keeps the upstream `LICENSE` file and records the origin here. Data Changes Council now focuses on a reusable skill and decision-record method rather than an installable application.
