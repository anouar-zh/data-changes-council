# LinkedIn launch copy

## Short project description

Data Changes Council is an open-source experiment in multi-model deliberation. It compares independent LLM answers, keeps dissent visible, and puts human approval before external actions.

## Launch post

Meerdere AI-modellen laten debatteren klinkt slim.

Maar wie controleert de uitkomst?

Ik ben begonnen aan een eigen experiment: Data Changes Council.

Het idee is eenvoudig.

Stel een lastige vraag aan meerdere modellen. Laat ze eerst zelfstandig antwoorden. Laat ze daarna elkaars redenering beoordelen. Houd verschillen en twijfel zichtbaar. Laat een mens beslissen wat er met de uitkomst gebeurt.

Een hoge overeenkomst is geen bewijs dat het antwoord klopt. Als alle modellen dezelfde verkeerde bron gebruiken, krijg je vooral dezelfde vergissing in meerdere varianten.

Daarom wil ik ook vastleggen welke bronnen zijn gebruikt, welke modellen en versies hebben geantwoord, waar ze het oneens zijn, hoeveel tijd en kosten de analyse vraagt en welke menselijke controle nog nodig is.

De eerste versie bouw ik voort op een open-source basis. Daarna voeg ik mijn eigen keuzes toe voor data-classificatie, governance, logging en menselijke goedkeuring.
